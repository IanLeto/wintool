# 代码片段存储目录

此目录用于存储内外网传输的代码片段，**不会被 git 追踪**。

## 目录说明

- 所有片段以 JSON 格式存储
- 文件名格式：`YYYYMMDD_HHMMSS.json`
- 此目录已在 `.gitignore` 中配置，不会被提交到远程仓库

## 使用方式

1. 在 Wintool 界面中打开"代码片段管理"工具
2. 创建、编辑、删除代码片段
3. 支持按标签、语言、方向分类
4. 支持搜索和快速复制

## 数据格式

```json
{
  "id": "20260512_134500",
  "title": "示例片段",
  "language": "python",
  "tags": ["工具", "示例"],
  "direction": "intranet_to_internet",
  "content": "代码内容...",
  "created_at": "2026-05-12 13:45:00",
  "updated_at": "2026-05-12 13:45:00"
}
```

## 注意事项

- ✅ 数据仅保存在本地
- ✅ 不会被 git 追踪
- ✅ 不会被推送到远程仓库
- ✅ 适合存储敏感代码片段
