# 导出目录结构工具 - 使用说明

## 功能概述

这个工具可以将Windows路径转换为WSL路径，并生成AI友好的目录树结构，方便你将项目结构提供给AI进行分析。

## 主要特性

### ✅ 已修复的问题

1. **Windows路径自动转换**
   - 自动识别并转换 `C:\Users\...` 为 `/mnt/c/Users/...`
   - 支持所有盘符（C:, D:, E: 等）
   - 自动处理反斜杠和正斜杠

2. **树状结构输出**
   - 使用 `├──` 和 `└──` 符号显示层级关系
   - 文件夹和文件分别用 📁 和 📄 图标标识
   - 显示文件大小（自动格式化为 KB/MB/GB）

3. **灵活的递归控制**
   - 可设置递归深度（1-10层）
   - 支持仅扫描一级目录
   - 避免扫描过深导致输出过大

4. **统计信息**
   - 显示文件夹和文件总数
   - 每个根目录单独统计
   - 可选择是否显示统计

5. **错误处理**
   - 权限拒绝时显示明确提示
   - 路径不存在时给出详细错误信息
   - 显示路径转换信息

## 使用方法

### 1. 输入路径

支持以下格式：

```
# Windows路径
C:\Users\YourName\Projects
D:\Media\Videos

# WSL路径
/mnt/c/Users/YourName/Projects
/mnt/d/Media/Videos

# 混合使用
C:\Projects
/mnt/d/Backup
```

### 2. 配置选项

- **仅一级**：只列出当前目录下的文件和文件夹，不递归
- **递归深度**：设置扫描的最大层级（1-10）
- **树状结构**：推荐开启，AI更容易理解
- **显示统计信息**：显示文件夹和文件数量

### 3. 生成预览

点击"生成预览"按钮，在右侧查看目录结构。

### 4. 复制或保存

- 点击"复制结果"将结构复制到剪贴板
- 展开"保存到文件"区域，填写输出路径并点击"写入文件"

## 技术细节

### 路径转换规则

```python
# Windows → WSL
C:\Users\Name\file.txt  →  /mnt/c/Users/Name/file.txt
D:\Data                 →  /mnt/d/Data
E:\Backup\2024          →  /mnt/e/Backup/2024

# 已经是WSL路径则不转换
/mnt/c/Projects         →  /mnt/c/Projects
/home/user/docs         →  /home/user/docs
```

### 文件大小格式化

- < 1KB: 显示为 B
- < 1MB: 显示为 KB
- < 1GB: 显示为 MB
- >= 1GB: 显示为 GB

### 深度控制

- 深度 1: 只显示根目录下的直接子项
- 深度 2: 显示到第二层
- 深度 0: 无限制（谨慎使用）

## 常见问题

### Q: 为什么有些文件夹显示"权限拒绝"？

A: 某些系统文件夹需要管理员权限才能访问。这是正常现象，工具会继续处理其他可访问的文件夹。

### Q: 输出太大怎么办？

A: 可以：
1. 减小递归深度
2. 使用"仅一级"选项
3. 分别扫描子目录

### Q: 可以同时扫描多个目录吗？

A: 可以！每行输入一个路径，工具会依次处理并在输出中用分隔线区分。

### Q: 支持网络路径吗？

A: 如果网络路径已经挂载到WSL，可以使用挂载点路径。
