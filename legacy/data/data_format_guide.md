# 数据文件说明

## 通用字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `更新时间` | string | 可选，页面顶部展示 |
| `数据说明` | string | 可选，副标题说明 |

## `shore_info.json`（上岸信息渠道）

- **`官网列表`**、**`人事考试网补充入口`**：数组，每项为：
  - `地区`：string
  - `官网`：string，单个 URL

## `provincial_exam.json`（省考公告入口）

- **`官网列表`**：数组，每项为：
  - `地区`：string，必填
  - `官网`：**string（单个 URL）或 string[]（多个 URL）**
  - `说明`：string，可选；多个 URL 时建议用中文顿号 `、` 分隔多个站点名称，便于页面拆成与链接一一对应的按钮文案；若段数与链接数不一致，则显示「入口 1」「入口 2」…

### 处理规则（省考）

1. `官网` 为字符串 → 该地区一张卡片，一个「打开官网」按钮。
2. `官网` 为数组 → 多个按钮；`说明` 按 `、` `，` `,` `;` `；` 拆分，若拆出段数 **等于** 链接数，则每段作为对应按钮文字；否则用「入口 1」… 占位。
3. 仅允许 `http` / `https` 链接。

## `text_viewer/`（文本阅览）

存放文本文件（`.txt`），工具会自动扫描并生成页签，支持快速切换和搜索过滤。

## `media_shelf/`（影视收藏）

存放多个清单文件（`.txt` / `.md` / `.csv` / `.json`），工具会解析并聚合展示。详见目录下的 `使用说明.txt`。

## `prompt_bank/`（提示词收纳）

存放本地文本/脚本等任意普通文件，在网页「提示词收纳」中编辑保存；不写后缀时默认 `.md`。仓库附带 `影视收藏_数据格式转换-AI提示词.md` 供复制给大模型做清单格式转换。

## `path_presets.json`（常用路径）

各工具页顶部的「常用路径」芯片由此文件生成。格式：

```json
{
  "presets": [
    { "label": "显示名称", "path": "/mnt/c/Users/你的用户名/Downloads" }
  ]
}
```

点击芯片会把 `path` 填入**该页第一个**带路径的输入框。另可使用输入框下方的 **「选择文件夹…」**（本机对话框，WSL 下一般为 Windows 资源管理器）与 **「粘贴 Windows 路径」**（从资源管理器地址栏复制 `C:\...` 后一键转为 `/mnt/c/...`）。

## 体重管理数据

体重管理工具使用 MySQL 数据库存储数据，不使用 JSON 文件。详见 `body_weight_README.md`。
