# 体重管理工具使用说明

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 初始化数据库

```bash
python init_body_weight_db.py
```

### 3. 启动应用

```bash
python app.py
```

访问 http://localhost:5001，点击「体重管理」工具。

---

## 功能说明

### 📊 仪表盘

- **当前体重**：最新记录的体重和7日移动平均
- **当前阶段**：自动判断（建立期/平台期/加速期/失控期）
- **本周执行率**：根据断食、戒糖、睡眠、运动计算
- **当前策略**：显示活跃的策略版本和运行天数
- **趋势图表**：最近30天体重变化曲线

### 📝 每日记录

**快速录入功能：**
- 点击「复制昨日」自动填充昨天的数据（暴食除外）
- 点击「加载」读取指定日期的历史记录
- 滑块实时显示精力/饥饿/心情数值

**记录字段：**
- 体重 (kg)
- 睡眠时长 (小时)
- 步数
- 运动时长 (分钟)
- 16:8 断食 (勾选)
- 戒糖 (勾选)
- 暴食 (勾选)
- 精力水平 (1-10)
- 饥饿水平 (1-10)
- 心情水平 (1-10)
- 备注

### 📈 趋势图表

- 支持查看 7/14/30/90 天趋势
- 显示实际体重和7日移动平均线
- 自动过滤空值

### 🎯 策略版本

**当前策略：**显示正在执行的策略详情

**创建新策略：**
- 版本名称：如 "v1.1 - 增加运动"
- 开始日期：新策略生效日期
- 核心策略：描述主要方法
- 变更变量：说明与上版本的差异
- 预期效果：预计达成的目标

**历史版本：**查看所有策略的执行记录

### 📤 数据导出

- 导出最近14天的完整数据
- 包含当前策略、阶段判断、趋势信息
- JSON 格式，可复制给 GPT 进行分析

## 核心算法

### 执行率计算

每日得分 = 0.3×断食 + 0.3×戒糖 + 0.2×睡眠(≥7h) + 0.2×运动(≥20min)

周执行率 = 最近7天平均得分

### 阶段判断

**失控期 (unstable)**
- 最近7天暴食 ≥ 3次，或
- 最近7天有5天睡眠 < 6小时

**平台期 (plateau)**
- 14天体重波动 < 0.5kg
- 执行率 ≥ 75%

**加速期 (accelerating)**
- 周下降 > 1kg
- 平均饥饿 ≤ 6
- 平均精力 ≥ 6

**建立期 (building)**
- 其他情况

### 7日移动平均

MA7(t) = 最近7天体重的平均值

## 使用建议

### 每日流程

1. **早晨**：测量体重（空腹、排便后）
2. **晚上**：打开工具，点击「每日记录」
3. 点击「复制昨日」快速填充
4. 修改今日实际数据
5. 点击「保存记录」

### 每周流程

1. 查看「仪表盘」了解本周执行率
2. 查看「趋势图表」观察体重变化
3. 根据阶段判断调整策略

### 策略调整

- **建议间隔**：至少14天
- **变量控制**：每次只改2个变量
- **记录预期**：明确写下预期效果
- **数据支撑**：基于趋势而非单日数据

## 常见问题

**Q: 数据库连接失败？**
A: 检查数据库服务是否运行，连接信息是否正确

**Q: 图表不显示？**
A: 确保已加载 Chart.js CDN，检查浏览器控制台错误

**Q: 如何备份数据？**
A: 使用 mysqldump 导出数据库，或使用「数据导出」功能

**Q: 可以删除记录吗？**
A: 当前版本不支持前端删除，可直接操作数据库

**Q: 支持多用户吗？**
A: 不支持，这是单用户工具

## 系统理念

1. **趋势优先**：所有判断基于趋势，不看单日数据
2. **版本管理**：每次调整必须记录版本
3. **异常即数据**：暴食、失眠都是数据，不是失败
4. **科学迭代**：控制变量，记录预期，验证效果
