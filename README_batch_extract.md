# 批量双层7z解压工具 - 使用说明

## 📋 功能概述

这是一个强大的批量解压工具，专门用于处理复杂的多层压缩文件结构。

### 核心功能

1. **双层解压**：自动处理 `外层.7z → 分卷.7z.001/.7z.002 → 最终内容` 的结构
2. **递归解压**：如果解压后仍是压缩文件（如 `H2224.7z删除`），自动继续解压
3. **智能清理**：成功解压后自动删除原始压缩包，保持目录整洁
4. **智能跳过**：自动识别已处理的目录，避免重复解压
5. **详细日志**：彩色输出，实时显示进度和统计信息

### 支持的场景

✅ **场景1：双层压缩**
```
H2195.7z (外层)
  └─ 解压后得到 → 202553115838.7z.001, 202553115838.7z.002 (分卷)
      └─ 再次解压 → 游戏文件
```

✅ **场景2：三层压缩**
```
H2224.7z (外层)
  └─ 解压后得到 → H2224.7z删除 (中间层)
      └─ 再次解压 → 游戏文件
```

✅ **场景3：单层压缩**
```
H2170.7z
  └─ 直接解压 → 游戏文件
```

✅ **场景4：已解压目录**
- 自动跳过已存在且包含游戏内容的目录

## 🚀 快速开始

### 1. 环境要求

- Python 3.6+
- 7z 工具（已安装）
- Linux/WSL 环境

### 2. 使用方法

#### 方法一：直接运行（推荐）

```bash
cd /home/ian/workdir/wintool
python3 batch_extract_7z.py
```

#### 方法二：设置为可执行文件

```bash
chmod +x batch_extract_7z.py
./batch_extract_7z.py
```

### 3. 配置说明

打开 `batch_extract_7z.py`，在文件开头找到配置区：

```python
# ==================== 配置区 ====================
SOURCE_DIR = "/mnt/y/新建文件夹"      # 源目录路径
PASSWORD = "erciyuan.org"             # 解压密码
DELETE_ORIGINAL = True                # 是否删除原始压缩包
MAX_DEPTH = 3                         # 最大递归解压深度
```

**配置项说明：**

| 配置项 | 说明 | 默认值 | 建议 |
|--------|------|--------|------|
| `SOURCE_DIR` | 包含.7z文件的目录 | `/mnt/y/新建文件夹` | 根据实际情况修改 |
| `PASSWORD` | 解压密码 | `erciyuan.org` | 保持不变 |
| `DELETE_ORIGINAL` | 成功后是否删除原始.7z | `True` | 建议True，节省空间 |
| `MAX_DEPTH` | 最大递归深度 | `3` | 防止无限循环，一般不需要修改 |

## 🔄 工作流程

### 完整处理流程

```
1. 扫描源目录
   └─ 查找所有 *.7z 文件
   
2. 对每个.7z文件：
   
   [阶段1] 第一次解压
   ├─ 创建临时目录: /mnt/y/新建文件夹/H2195/.temp_stage1_xxx/
   ├─ 解压外层.7z到临时目录
   └─ 检查解压结果
   
   [阶段2] 处理分卷（如果存在）
   ├─ 查找分卷文件: *.7z.001, *.001
   ├─ 解压分卷到最终目录: /mnt/y/新建文件夹/H2195/
   └─ 删除临时目录
   
   [阶段3] 递归解压
   ├─ 扫描最终目录中的所有压缩文件
   ├─ 逐个解压（如 H2224.7z删除）
   ├─ 删除已解压的中间压缩文件
   └─ 重复直到没有压缩文件或达到最大深度
   
   [阶段4] 清理
   └─ 删除原始.7z文件（如果配置为True）
   
3. 输出统计信息
```

## ⚠️ 注意事项

### 1. 磁盘空间

- 解压过程需要额外空间（约为压缩包大小的2-3倍）
- 建议确保至少有 **50GB** 以上的可用空间
- 成功解压后会自动删除原始压缩包以释放空间

### 2. 处理时间

- 单个大文件（10GB+）可能需要 **10-30分钟**
- 整个批处理可能需要 **数小时**
- 建议在空闲时间运行，或使用 `nohup` 后台运行

### 3. 中断恢复

- 如果中途中断，再次运行会自动跳过已处理的目录
- 临时目录（`.temp_stage1_xxx`）会在下次运行时自动清理

### 4. 错误处理

- 密码错误：检查 `PASSWORD` 配置
- 文件损坏：会跳过该文件，继续处理其他文件
- 权限问题：确保对目标目录有写权限

## 🐛 故障排除

### 问题1：提示"7z not found"

**解决方案：**
```bash
sudo apt-get update
sudo apt-get install -y p7zip-full
```

### 问题2：权限被拒绝

**解决方案：**
```bash
chmod +x batch_extract_7z.py
# 或者确保对目标目录有写权限
```

### 问题3：解压失败

**可能原因：**
- 密码错误
- 文件损坏
- 磁盘空间不足

**解决方案：**
- 检查密码配置
- 使用 `7z t -p"密码" 文件.7z` 测试文件完整性
- 清理磁盘空间

### 问题4：中文乱码

**解决方案：**
```bash
export LANG=zh_CN.UTF-8
python3 batch_extract_7z.py
```
