# 数据文件说明

## 通用字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `更新时间` | string | 可选，页面顶部展示 |
| `数据说明` | string | 可选，副标题说明 |

## `shore_info.json`（上岸信息渠道）

- **`官网列表`**、**`人事考试网补充入口`**：数组，每项为：
  - `地区`：string
  - `官网`：string，单个 URL

## `provincial_exam.json`（省考公告入口）

- **`官网列表`**：数组，每项为：
  - `地区`：string，必填
  - `官网`：**string（单个 URL）或 string[]（多个 URL）**
  - `说明`：string，可选；多个 URL 时建议用中文顿号 `、` 分隔多个站点名称，便于页面拆成与链接一一对应的按钮文案；若段数与链接数不一致，则显示「入口 1」「入口 2」…

### 处理规则（省考）

1. `官网` 为字符串 → 该地区一张卡片，一个「打开官网」按钮。
2. `官网` 为数组 → 多个按钮；`说明` 按 `、` `，` `,` `;` `；` 拆分，若拆出段数 **等于** 链接数，则每段作为对应按钮文字；否则用「入口 1」… 占位。
3. 仅允许 `http` / `https` 链接。

## `milestones.json`（关键时间节点）

- **`subtitle`**：可选，页面副标题说明。
- **`items`**：数组，每项为：
  - **`title`**（或 `标题` / `name`）：string，节点名称
  - **`date`**（或 `日期`）：string，支持 `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY.MM.DD`
  - **`time`**（或 `时刻`）：可选，如 `09:00`，显示在日期旁
  - **`note`**（或 `说明` / `备注`）：可选，短说明

节点按日期**升序**排列展示；相对今天显示「还有 N 天」「就是今天」「已过 N 天」；未来节点略强调，已过去节点略弱化。无通知、无提醒，仅展示。
