# Wintool 新功能说明

本文档介绍最新添加的三个功能。

## 1. 命令片段管理器 (Command Snippets)

### 功能说明
管理常用的SQL、PromQL、Shell等命令片段，方便快速查找和复制。

### 特点
- **简单易用**：专注于内网环境，界面简洁
- **支持类型**：SQL、PromQL、Shell、其他
- **快速搜索**：支持按标题、标签、内容搜索
- **一键复制**：点击即可复制命令到剪贴板
- **标签管理**：可为每个命令添加多个标签

### 使用方法
1. 在 Wintool 主界面选择"命令片段"工具
2. 点击"+ 新建片段"添加新命令
3. 填写标题、选择类型、粘贴命令内容
4. 可选添加标签（用逗号分隔）
5. 保存后即可在列表中查看和使用

### 数据存储
- 数据文件：`data/command_snippets.json`
- 格式：JSON
- 可手动编辑或备份

### 示例
```json
{
  "snippets": [
    {
      "id": "snippet_1234567890",
      "title": "查询用户列表",
      "type": "sql",
      "content": "SELECT * FROM users WHERE created_at > '2024-01-01' LIMIT 10;",
      "tags": ["查询", "用户"],
      "created_at": "2026-05-07T19:30:00"
    }
  ]
}
```

## 2. 密码管理器 (Password Manager)

### 功能说明
简单的内网账号密码管理器，存储账号、密码和对应的链接。

### 特点
- **本地存储**：数据保存在本地，无需联网
- **密码保护**：支持显示/隐藏密码
- **快速复制**：一键复制用户名或密码
- **链接跳转**：点击链接直接打开网站
- **搜索功能**：快速查找账号

### 使用方法
1. 在 Wintool 主界面选择"密码管理"工具
2. 点击"+ 新建账号"添加新账号
3. 填写标题、链接、用户名、密码
4. 可选添加备注说明
5. 保存后即可在列表中查看和使用

### 安全提示
⚠️ **重要**：
- 数据以明文形式存储在本地
- 仅适用于内网环境
- 请妥善保管 `data/passwords.json` 文件
- 建议定期备份

### 数据存储
- 数据文件：`data/passwords.json`
- 格式：JSON
- 可手动编辑或备份

### 示例
```json
{
  "accounts": [
    {
      "id": "account_1234567890",
      "title": "公司OA系统",
      "url": "https://oa.company.com",
      "username": "zhangsan",
      "password": "password123",
      "note": "每月需要修改密码",
      "created_at": "2026-05-07T19:30:00"
    }
  ]
}
```

## 3. 打包脚本 (Package Script)

### 功能说明
将 Wintool 工具打包成密码保护的压缩包，方便传输到内网环境。

### 特点
- **仅打包代码**：不包含 data 目录，减小文件大小
- **密码保护**：压缩包密码为 `123`
- **自动命名**：文件名包含时间戳
- **排除无用文件**：自动排除 .git、__pycache__、.venv 等

### 使用方法

**Linux/WSL:**
```bash
cd /home/ian/workdir/wintool
bash scripts/package_wintool.sh
```

**输出示例:**
```
=========================================
Wintool 打包工具
=========================================
项目目录: /home/ian/workdir/wintool
输出文件: wintool_20260507_193000.zip
压缩密码: 123

正在打包代码文件...

=========================================
打包完成！
=========================================
文件: wintool_20260507_193000.zip
大小: 2.3M
密码: 123

解压命令: unzip -P 123 wintool_20260507_193000.zip
=========================================
```

### 打包内容
包含以下文件和目录：
- `app.py` - 主程序
- `requirements.txt` - Python依赖
- `README.md` - 说明文档
- `tools/` - 工具模块
- `templates/` - HTML模板
- `static/` - 静态资源
- `scripts/` - 脚本文件
- `startup/` - 启动脚本
- `windows/` - Windows启动脚本
- `docs/` - 文档

### 排除内容
- `data/` - 数据目录（用户数据）
- `.git/` - Git仓库
- `__pycache__/` - Python缓存
- `.venv/` - 虚拟环境
- `*.pyc` - 编译文件
- `*.log` - 日志文件

### 解压方法

**Linux/WSL:**
```bash
unzip -P 123 wintool_20260507_193000.zip
```

**Windows:**
使用 7-Zip 或 WinRAR，输入密码 `123`

## 常见问题

### Q: 如何备份我的数据？
A: 复制 `data/` 目录即可备份所有数据。

### Q: 密码管理器安全吗？
A: 仅适用于内网环境，数据以明文存储。如需更高安全性，请使用专业密码管理工具。

### Q: 打包脚本需要什么依赖？
A: 需要 `zip` 命令。Linux 上可通过 `sudo apt-get install zip` 安装。

### Q: 如何在新环境使用？
A: 
1. 解压打包文件
2. 安装 Python 依赖：`pip install -r requirements.txt`
3. 运行启动脚本：`bash startup/run.sh`
4. 根据需要创建 `data/` 目录并添加数据
