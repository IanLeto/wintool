## 四、你生成脚本时必须遵守的规则

### 1. 脚本语言和基本结构（bash）

- 你生成的脚本必须是 **bash 脚本**，开头推荐如下：

  ```bash
  #!/usr/bin/env bash
  set -e
  ```

  - `set -e`：一旦有命令出错（返回非 0），整个脚本立刻退出，以免生成错误文件。

- 如果你需要临时变量，可以直接使用标准 bash 语法（如 `temp_files=()` 等），但**尽量保持脚本简单、直观**。

### 2. 片段切割原则

- 对于每一个「需要保留或重复」的时间片段，你要生成一条 `ffmpeg` 命令，把它剪出来到一个临时文件，比如：

  ```bash
  ffmpeg -y -ss 00:02:00 -to 00:19:00 -i "meyd-906ch.mp4" -c copy "temp_01.mp4"
  ffmpeg -y -ss 00:29:00 -to 00:44:00 -i "meyd-906ch.mp4" -c copy "temp_02.mp4"
  ```

- 剪切阶段统一使用 `-c copy` 做「无损裁剪」，这样：
  - 速度快；
  - 不损失画质；
  - 后续再决定是否整体重编码。

- 如果片段是「从某时间点到结尾」，可以不写 `-to`，例如：

  ```bash
  ffmpeg -y -ss 01:51:00 -i "meyd-906ch.mp4" -c copy "temp_05.mp4"
  ```

- 对于「重复」片段：  
  - 建议**一个片段只剪一份**（如 `temp_03.mp4`）；  
  - 在 concat 阶段中重复引用该文件多次，而不是再剪出 `temp_03_copy2.mp4` 等，除非有特别原因。

### 3. concat 拼接原则

- 剪好所有 `temp_xx.mp4` 后，生成一个 `concat.txt` 文件，用于 `ffmpeg` 的 concat demuxer，示例（bash 写法）：

  ```bash
  printf "file 'temp_01.mp4'\n" > concat.txt
  printf "file 'temp_02.mp4'\n" >> concat.txt
  printf "file 'temp_03.mp4'\n" >> concat.txt
  printf "file 'temp_04.mp4'\n" >> concat.txt
  printf "file 'temp_05.mp4'\n" >> concat.txt
  ```

- 然后使用 concat 模式进行拼接：

  - **无损拼接（不重编码）版本：**

    ```bash
    ffmpeg -y -f concat -safe 0 -i concat.txt -c copy "输出文件名.mp4"
    ```

  - **重编码（使用 NVENC）版本示例：**

    ```bash
    ffmpeg -y -f concat -safe 0 -i concat.txt \
      -c:v h264_nvenc -preset p5 -cq 23 \
      -c:a aac -b:a 160k \
      "输出文件名_edit_nvenc.mp4"
    ```

- 你要根据我对「是否重编码、目标大小、画质」的描述，自动选择：
  - `-c copy` 直接输出，或者  
  - 使用 NVENC，并设置合适的 `-preset` / `-cq` / `-c:a` / `-b:a` 参数。

### 4. 清理临时文件

- 在脚本的最后，你要删除所有中间文件，比如：

  ```bash
  rm -f temp_01.mp4 temp_02.mp4 temp_03.mp4 temp_04.mp4 temp_05.mp4 concat.txt
  ```

- 如果临时片段数量不固定，你要按**实际使用到的 temp 文件名**来写 `rm -f`，不要遗漏，也不要删除不存在的文件名（可以多写几个不影响，因为 `rm -f` 不会报错）。

### 5. 路径与引号处理（非常重要）

- 所有涉及路径或文件名的地方，**必须用双引号包裹**，例如：

  ```bash
  ffmpeg -y -ss 00:02:00 -to 00:19:00 -i "/c/video/meyd-906ch.mp4" -c copy "temp_01.mp4"
  ```

- 要假定路径中可能包含：
  - 空格  
  - 中文  
  - 日文  
  - 括号等符号  

- 你生成的脚本里，**不能要求我再去手动转义或修改路径**，要直接可用。
